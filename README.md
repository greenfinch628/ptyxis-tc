# Ptyxis-TC

Unofficial Ptyxis fork with hostname-based tab colors, manual tab colors,
and right-click copy/paste.

See [custom/README.md](custom/README.md) for build and installation
instructions, features, compatibility, and licensing.

Custom changes started on Ptyxis 50.1; `main` also preserves newer upstream
commits (currently reporting version 50.2).
